# Brothers Tire LLC — marketing site

Plain HTML/CSS/JS built with [Vite](https://vitejs.dev). No framework.

## Project structure

```
src/            Vite root
  index.html
  css/
  js/
public/         Static assets (logo, favicons, photos) — copied to the build output root
dist/           Build output (gitignored, generated by `npm run build`)
```

## Local development

```
npm install
npm run dev       # starts a local dev server with hot reload
npm run build     # builds the production site into dist/
npm run preview   # serves the dist/ build locally to sanity-check it
```

Requires Node.js `>=20.19.0` (Vite 8). Node 22 LTS is recommended and is what the Amplify build uses (see below).

## Deploying to AWS Amplify Hosting

This repo is set up to deploy directly via Amplify Hosting using the `amplify.yml` at the repo root:

- **preBuild**: installs Node 22 via `nvm` and runs `npm ci`
- **build**: runs `npm run build`
- **artifacts**: publishes `dist/`

In the Amplify console, connect this repository/branch and it will pick up `amplify.yml` automatically. No manual build settings are required.

## KurumaWorks booking

Every "Book Now" / "Book Us on Kuruma" button routes through a single constant, `KURUMA_URL`, defined in `src/js/main.js`. To update the shop's KurumaWorks id later, change that one constant — no other files need edits.

Current value: `https://kurumaworks.com/mechanics/nc/durham/brothers-tires-service`

## Analytics

Google Analytics (gtag.js) is wired in with measurement ID `G-S97T77J6QW`, loaded as high in `<head>` as possible in `src/index.html`.
